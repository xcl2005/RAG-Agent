# 企业知识库 RAG Agent 示例资料

本项目实现一个面向企业内部资料的大批量检索问答系统。系统支持 PDF、Word、Markdown、TXT、HTML 等资料导入。

## 检索流程

系统使用混合检索策略。第一阶段使用 Qdrant 进行向量召回，适合语义相似问题。第二阶段使用 SQLite FTS5 进行关键词召回，适合精确名词、编号、条款和错误码。两路召回结果会通过 RRF 进行融合。

## Rerank

初始召回结果可能包含噪声，因此系统使用 CrossEncoder reranker 对候选片段重新排序。CrossEncoder 会同时读取用户问题和候选文本，并输出相关性分数。

## Chunk 调优

chunk size 太小会导致上下文不完整；chunk size 太大则会导致噪声过多。一般中文资料可以从 700 到 900 字符开始调试，overlap 可以设置为 100 到 150 字符。

## 幻觉处理

系统通过以下方式降低幻觉：只允许模型基于检索上下文回答；关键结论必须带来源引用；检索结果不足时拒答；使用低 temperature 生成答案；API 返回 sources 方便人工核查。

## Agent 流程

LangGraph 负责把问答过程编排为多个节点：问题改写、检索、证据判断、答案生成。相比普通函数调用，这种图结构更容易扩展人工确认、工具调用和多轮状态管理。
