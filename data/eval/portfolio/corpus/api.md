# 星河工坊：查询 API 契约（虚构教学资料）

## 请求和幂等

POST /v1/answers 接收 question 和 request_id。question 最长 2000 字符。客户端重试时复用同一个 request_id；服务端缓存同一租户同一标识的结果 10 分钟，防止重复计费。不同租户不能共享幂等结果。

## 错误与重试

429 表示速率限制，响应中的 Retry-After 是建议等待秒数。503 表示暂时不可用。客户端对 429 和 503 使用指数退避并加入随机抖动，最多重试两次。401 表示凭证无效，不能靠重复请求解决。

## 超时

查询 API 的总超时为 30 秒。模型调用、检索和重试共用这份预算，超过预算返回可诊断错误，不伪装成证据不足。
